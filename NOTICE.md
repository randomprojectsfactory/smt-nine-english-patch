# Project notes

This is an unofficial fan translation for the Japanese Xbox release of Shin Megami Tensei NINE. It is not affiliated with the game's developers or publisher.

The patch requires the matching original game image. Original game files, ISO images and extracted installations are not distributed here. The original font textures are retained; the text-rendering and layout changes are part of the patch.

Translation drafts and technical work were assisted by Codex. Japanese text, native game behavior and the owner's playtesting feedback guide corrections. Review and testing are still in progress.

Patch generation and verification use [xdelta3](https://github.com/jmacd/xdelta). Local Xbox disc packaging was checked with [extract-xiso](https://github.com/XboxDev/extract-xiso). These tools are not bundled in this repository.
